# 01 — Project Overview

## Nama proyek

Personal Developer Portfolio — Anang Muhamad Lutfi

## Ringkasan

Website portfolio pribadi dinamis untuk membangun personal branding profesional sebagai developer. Website menampilkan profil, keahlian, pengalaman, proyek, sertifikat, artikel, serta kanal kontak. Konten dikelola melalui admin CMS.

## Visi

Menyajikan rekam jejak dan kemampuan teknis secara kredibel, mudah dipahami recruiter, calon klien, kolaborator, dan komunitas teknologi.

## Sasaran

1. Pengunjung memahami profil dan fokus profesional dalam beberapa detik.
2. Pengunjung dapat meninjau proyek beserta kontribusi dan teknologi yang digunakan.
3. Recruiter dapat mengunduh CV dan menghubungi pemilik.
4. Pemilik dapat memperbarui konten melalui admin tanpa mengubah kode.
5. Website mudah ditemukan melalui mesin pencari dan nyaman di perangkat mobile.

## Target audiens

- Recruiter dan HR.
- Perusahaan yang mencari backend/full-stack developer.
- Calon klien atau partner.
- Developer dan komunitas teknologi.
- Pengunjung umum.
